# MCP Bridge 快速修复指南

## 问题症状
```
Connect timeout after 8000ms (url ws://127.0.0.1:18800)
Is the bridge server running and reachable?
```

## 原因
**MCP Server 进程未启动** ← 只需启动这个即可解决

三层架构中缺少中间层：
- ✓ Gateway 在运行
- ✗ **MCP Server 未运行** ← 问题根源
- ✗ EDA 插件无法连接

---

## 🚀 一分钟快速修复

```bash
# 1. 进入 EDA 目录
cd /home/bitq/github/hermes-agent-learning/EDA

# 2. 启动完整栈（Gateway + MCP Server）
./start-eda-mcp.sh

# 3. 等待 2 秒
sleep 2

# 4. 验证已启动
ps aux | grep node | grep -E "gateway|mcp" | grep -v grep
```

**预期输出**（看到两个 node 进程）：
```
bitq  90369  0.0  0.7  ...  node server.js        ← Gateway
bitq  90370  0.0  0.5  ...  node /home/bitq/...   ← MCP Server
```

## ✅ 验证连接正常

### 方法 1: 查看进程
```bash
ps aux | grep "index.js"
# 应该看到：node /home/bitq/mcp-servers/jlcmcp/dist/index.js
```

### 方法 2: 查看端口
```bash
ss -tlnp | grep 18800
```

1. 打开 LCEDA Pro
2. 菜单 → 高级 → 扩展管理器
3. 找到 `jlc-bridge` 扩展
4. 应显示: `"connected": true`

## 🔧 如果还是不行

### 步骤 1: 完全重启
```bash
# 停止所有服务
./stop-eda-mcp.sh

# 清空旧进程（以防万一）
killall node 2>/dev/null

# 重新启动
./start-eda-mcp.sh

# 验证
sleep 2 && ps aux | grep node | grep -v grep
```

### 步骤 2: 检查依赖
```bash
# Gateway 依赖
cd /home/bitq/mcp-servers/jlcmcp/gateway
npm install

# MCP Server 依赖
cd /home/bitq/mcp-servers/jlcmcp
npm install 2>/dev/null || echo "已安装"
```

### 步骤 3: 检查网络
```bash
# 查看 18800 端口状态
netstat -tln | grep 18800
# 或
lsof -i :18800

# 测试 WebSocket 连接
curl -i http://127.0.0.1:18800/
# 应返回 426 Upgrade Required
```

### 步骤 4: 查看日志
```bash
# 如果使用 systemd
sudo journalctl -u eda-mcp.service -n 50

# 在脚本中查看错误
bash -x ./start-eda-mcp.sh
```

## 🛠️ 配置自动启动（可选）

### 使用 Systemd

```bash
# 安装服务
sudo cp /home/bitq/github/hermes-agent-learning/EDA/eda-mcp.service \
  /etc/systemd/system/

# 启用自启
sudo systemctl enable eda-mcp.service

# 启动服务
sudo systemctl start eda-mcp.service

# 查看状态
sudo systemctl status eda-mcp.service

# 查看日志
sudo journalctl -u eda-mcp.service -f
```

### 使用 supervisor（备选）

```bash
# 编辑配置
sudo vim /etc/supervisor/conf.d/eda-mcp.conf
```

```ini
[program:eda-mcp]
command=/home/bitq/github/hermes-agent-learning/EDA/start-eda-mcp.sh
user=bitq
autorestart=true
stdout_logfile=/var/log/eda-mcp.log
stderr_logfile=/var/log/eda-mcp-error.log
```

```bash
# 重启 supervisor
sudo systemctl restart supervisor
sudo supervisorctl status eda-mcp
```
