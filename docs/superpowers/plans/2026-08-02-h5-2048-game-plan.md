### Task 3: 启动本地 HTTP 服务（端口 8000，后台运行）

**Files:**
- No files created. Runs a long-lived process: `python3 -m http.server`

- [ ] **Step 1: 检查 8000 端口是否被占用**

Run:
```bash
if command -v ss >/dev/null 2>&1; then ss -tlnp | grep ':8000 ' || echo "PORT_8000_FREE"; else netstat -tlnp 2>/dev/null | grep ':8000 ' || echo "PORT_8000_FREE"; fi
```
Expected output: `PORT_8000_FREE`。如果显示 LISTEN 状态，使用端口 8080（以下步骤替换 `--bind 127.0.0.1 --port 8000` 为 `--port 8080`），并在 Task 4 中同步修改 URL。

- [ ] **Step 2: 在 H5 目录下启动 HTTP server（非阻塞后台运行，绑定 127.0.0.1）**

Run (cwd=`/home/bitq/github/H5`, blocking=`false`, wait_ms_before_async=`2000`):
```bash
cd /home/bitq/github/H5 && python3 -m http.server 8000 --bind 127.0.0.1
```
（如果 python3 失败，降级命令：`python2 -m SimpleHTTPServer 8000`）

- [ ] **Step 3: 等待 2 秒，确认服务进程存活并监听**

Run:
```bash
sleep 2 && curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8000/
```
Expected: `200`（H5 目录列表响应或 403 都可以，只要有 HTTP 响应即可；核心验证放在 Task 4 Step 1 针对具体游戏文件）。
