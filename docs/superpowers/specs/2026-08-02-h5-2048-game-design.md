### 核心功能亮点
- **平滑滑动动画**：方块滑行 + 新方块弹出 + 合并弹跳效果
- **一步 Undo**：可撤销上一步操作，包括从死局中恢复
- **得分浮动反馈**：每次合并显示 `+N` 得分飘字
- **正确的死局检测**：相邻相等方块 / 空格子的完整判定
- **胜利状态**：达到 2048 后可继续挑战更高分数
- **持久化存储**：最高分 + Top5 排行榜（localStorage）
- **双输入支持**：键盘（方向键/WASD）+ 触摸滑动
- **响应式**：适配桌面与移动端屏幕
- **单元测试**：核心移动/合并逻辑附带 DOM-free 测试（`node test-logic.js`），覆盖：
  - 四方向滑动、单/双合并
  - "不允许三连合并"规则
  - 胜利检测、死局锁定
  - Undo 系统（还原精度、一步限制、空操作不覆盖快照、死局救援、网格-方块一致性）

## 4. 技术架构

### 4.1 技术栈
| 层 | 技术 |
|---|---|
| 结构 | HTML5（语义化布局） |
| 样式 | CSS3（Grid 布局、CSS 变量、transition/keyframes 动画） |
| 逻辑 | Vanilla JavaScript（ES6+，无框架） |
| 持久化 | Web API: `localStorage` |
| 运行时 | 现代浏览器（Chrome 90+ / Firefox 88+ / Safari 14+ / Edge 90+） |

### 4.2 代码组织（单文件 game.js）
- **Grid 状态层**：二维数组表示棋盘，纯函数式的 move/merge 逻辑（DOM-free，便于测试）
- **渲染层**：读取 grid 状态，操作 DOM 更新方块位置与颜色
- **输入适配层**：键盘事件 + 触摸事件（touchstart/touchend 阈值判定滑动方向）
- **状态管理层**：分数、最高分、历史快照（用于 Undo）、胜利/死局 flag

### 4.3 运行方式（两种皆可）
1. **直接打开**：双击 `index.html`（最简单，但部分浏览器 localStorage 策略在 `file://` 协议下可能受限）
2. **本地 HTTP 服务（推荐）**：`python3 -m http.server 8000` → 访问 `http://localhost:8000/2048-merger/`

## 7. 风险与回退

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| GitHub 连接超时 / 克隆失败 | 中 | 阻塞 | 重试 2 次，仍失败则改用方案B (Tetris) 或方案C |
| Python3 未安装 | 低 | 无法启动 HTTP server | 检测后降级用 `python2` 或 `npx serve` |
| 端口 8000 被占用 | 低 | 服务无法启动 | 自动切换到 8080 / 9000 等空闲端口 |
| 单文件 game.js 在 file:// 下行为异常 | 低 | 功能不完整 | 强制使用 HTTP server 方式运行 |
